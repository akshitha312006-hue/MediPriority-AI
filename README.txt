MEDIPRIORITY AI — SETUP GUIDE
=============================
Features: patient intake, illustrative priority indicators, dashboard counts, SQLite
storage, searchable/filterable records, workflow status updates, and record deletion.

Technology: Python + Flask, HTML/CSS/JavaScript, SQLite.

RUN ON WINDOWS (VS CODE OR COMMAND PROMPT)
1. Install Python 3.10+ from https://www.python.org/downloads/ and enable "Add Python to PATH".
2. Extract this ZIP.
3. Open the extracted project folder in VS Code or Command Prompt.
4. Run these commands one at a time:
   py -m venv .venv
   .venv\Scripts\activate
   py -m pip install -r requirements.txt
   py app.py
5. Open http://127.0.0.1:5000 in your browser. Keep the terminal open; Ctrl+C stops the server.

DATABASE
The medipriority.db SQLite file is created automatically. Records persist between runs as
long as the database file is kept. Deleting it resets saved records.

RESPONSIBLE USE
Priority categories are generated by simple demonstration rules, not a validated clinical
model. Results may be inaccurate and are not a diagnosis or medical advice. Do not use this
tool to make real medical decisions or store real patient data. In an emergency, contact
local emergency services immediately.
